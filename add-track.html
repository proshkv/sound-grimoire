Добавление трека по ссылке archive.org

Вспомогательный инструмент — не часть самого архива и никак с ним не связан (в tracks.json ничего не пишет автоматически). Вставляете ссылку на archive.org → инструмент подтягивает название, автора, длительность и дату загрузки через Metadata API archive.org → вы проверяете и поправляете вручную (автораспознавание имени/автора по «вычурным» шрифтам и без чёткого разделителя не идеально) → копируете готовый JSON и вставляете в tracks.json.
